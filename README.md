# GeoVistar 🏠📐  
### AI-Powered Augmented Reality Room Designer

## 🚀 Live Demo
👉 https://huggingface.co/spaces/kalpkanungo/GeoVistar

---

## 🧠 Overview

GeoVistar is an AI-powered AR visualization system that:

- Detects floor plane using depth estimation
- Performs geometric plane fitting
- Segments scene using YOLOv8
- Overlays virtual furniture realistically into room images

This project integrates Computer Vision + Geometry + Deep Learning to create a resume-ready AR pipeline.

---

## 🛠 Tech Stack

- Python
- OpenCV
- PyTorch
- Ultralytics YOLOv8
- NumPy
- SciPy
- Gradio (for deployment)
- HuggingFace Spaces
